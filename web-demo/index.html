Privacy by design. This preview has no file-upload API, network submission, cloud analysis or data storage. Avoid opening sensitive projects on devices you do not trust.
What does the scanner cover?

Heuristic patterns for selected keys, credentials, debug flags and license flags. Supported text extensions include Python, JavaScript, TypeScript, JSON, YAML, Markdown, TOML and .env. Files over 1 MB, unsupported files and uncertain encodings are reported as skipped. It does not scan Git history, dependencies, vulnerabilities or binaries.
